# MVP Roadmap

## Goal

Launch a first working version that proves one question:

Will users return to the same profiles for recurring text-only companionship?

## Phase 1: Foundation

- create app structure
- define database schema
- establish API conventions
- set up frontend routing and shared UI styles

## Phase 2: Auth And Profiles

- signup
- login
- create profile
- edit bio
- choose vibe tags
- set profile boundaries

## Phase 3: Discovery And Reconnect

- browse profiles
- view profile details
- favorite profiles
- list previous chats
- reconnect from history

## Phase 4: Chat MVP

- create or reopen conversation
- send text messages
- poll for new messages
- show unread state

## Phase 5: Safety MVP

- block phone numbers, emails, links, and social handles
- rate-limit new users
- report/block/mute
- basic spam scoring

## Phase 6: Monetization MVP

- simple virtual gifts
- cosmetic rewards
- profile boost

## Phase 7: Admin Basics

- reported users view
- flagged messages view
- profile suspension tools

## Launch Metrics

We should track:

- signups
- profile completion rate
- chat starts
- repeat conversations
- favorites per user
- reports per 100 chats
- gifts sent

## Stop Or Continue Decision

Continue if:

- users repeatedly return to the same profiles
- profile owners stay active
- abuse remains manageable

Pause or rethink if:

- chats are mostly one-off
- moderation load becomes too high
- users constantly try to move off-platform
